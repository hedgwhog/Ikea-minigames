# Ikea-rooms
**If you just want to play it, go to this [website](https://ikea.hedgwhog.com/)**
- You don't need to make an account. You can play on desktop or phone, but I recommend desktop for the best experience.
- It is foccused on multiplayer, but you can't play on the same device with multiple people. (You need keyboard buttons)

## What you need

- [Node.js](https://nodejs.org) version **20.9 or higher**

## Run it

1. Open a terminal in the project folder.
2. Install everything (only once needed):
   ```bash
   npm install
   ```
3. Start the app:
   ```bash
   npm run dev
   ```
4. Open **http://localhost:3000** in your browser.

To stop the site, press `Ctrl + C` in the terminal.

## Misc
- **On your phone:** make sure your phone is on the same wifi as your computer. In the terminal, look for the line `Network: http://192.168.x.x:3000` and open that address on your phone.

No database is needed to run it on your own device.
